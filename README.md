# Lab-4
AI IMAGE GENERATION TOOLS

The same aviation image-generation prompt was tested using 7 different AI tools. The purpose was to understand how AI-generated visuals can be used for different aviation marketing and communication activities.

AI Tool	Intended Use
ChatGPT	Airline advertisements
Ideogram	Airport social-media campaigns
Gemini	Promotional airport visuals
Perplexity	Destination-marketing visuals
Leonardo AI	Marketing visuals
Adobe Firefly	Presentation backgrounds
DeepAI	Loyalty-programme campaigns
Common Prompt

Create a professional promotional image of young travellers inside a modern airport terminal, using blue and white colours, natural lighting and a landscape layout. Do not include airline logos or text.

The same basic prompt was used across the tools, while the intended business purpose varied, such as airline advertising, social-media campaigns, destination marketing, presentations and loyalty programmes.

⭐ Key Learning

Different AI image-generation tools can create visuals from the same basic prompt, but the output can be used for different business purposes depending on the requirement.

Prompt → AI Image Tool → Visual Output → Marketing Use

Why This Matters in Aviation

AI-generated images can help aviation businesses create promotional content more quickly for airlines, airports, destinations, presentations and customer campaigns. However, the generated image should still be reviewed before use.

Remember

Before using an AI-generated aviation image, check:

Visual quality
Brand suitability
Accuracy
Unwanted logos/text
Suitability for the intended campaign

One-line exam point:
AI image-generation tools help aviation businesses create marketing visuals efficiently, but human review is necessary before final use.
